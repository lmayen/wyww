## About this project

This project is a **fake website created for frontend development courses and exercises**.

Its purpose is to provide students with a concrete Angular application they can explore, modify, and use as a reference while learning frontend development.

The project deliberately favors **simplicity and speed of implementation over completeness and production quality**.

Some parts of the application may therefore be:

- simplified;
- unfinished;
- duplicated;
- loosely organized;
- insufficiently validated;
- insecure by production standards;
- implemented specifically to demonstrate a frontend concept.

The project was initially created using Angular's `--minimal` option, so its structure is intentionally lighter than a standard Angular project.
